# Skin Cancer Classifier — Malignant vs Benign Tumour

GET 324 (Artificial Intelligence and Machine Learning) — Laboratory Exercise 10 Mini-Project
University of Uyo | Group of 12

## Overview

A Convolutional Neural Network (custom CNN and MobileNetV3 transfer learning) that
classifies dermoscopic skin lesion images as **benign** or **malignant**, deployed as
an interactive Streamlit web application.

## Dataset

**Skin Cancer:Malignant vs Benign Tumour** (Kaggle, user `fanconic`), sourced from the ISIC
Archive: https://www.kaggle.com/datasets/fanconic/skin-cancer-malignant-vs-benign

Download it and arrange it as:

```
data/
  train/
    benign/
    malignant/
  test/
    benign/
    malignant/
```

## Project Structure

```
├── app.py                # Streamlit application
├── train_model.py        # Model training script (custom CNN + transfer learning)
├── requirements.txt
├── .gitignore
├── models/               # Saved .keras models (generated by train_model.py)
└── results/              # Training curves and confusion matrices
```

## Setup and Local Run

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 1. Train the model (place the dataset in data/ first)
python train_model.py

# 2. Launch the app
streamlit run app.py
```
