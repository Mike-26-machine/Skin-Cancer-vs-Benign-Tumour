

## How to Use the App

1. Open the deployed app URL (or `http://localhost:8501` locally).
2. Upload a dermoscopic image of a skin lesion (`.jpg`, `.jpeg`, or `.png`).
3. The app displays the predicted class (benign/malignant) with confidence scores.
